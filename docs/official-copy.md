# MoYu-Cloud 官方文案

## 标准介绍

MoYu-Cloud 是独立开发者的创作神器。通过统一模板、业务建模和代码生成，把一个想法快速变成可运行、可修改、可独立部署的真实产品。

## 核心口号

> 从业务模型，到可部署代码。

## 品牌副标题

> 少写重复代码，把时间留给真正的业务。

## 简短介绍

描述你的想法，生成表结构、API、页面、权限、审计和部署配置；代码归创作者所有，可进入 Git 并独立演进。

## 边界表达

MoYu-Cloud 不是在线低代码运行平台，也不是另一个通用后台脚手架。它与 Codex、Claude Code 等 AI 工具配合，把个人验证过的创作方法沉淀为可重复使用的产品生产线。
