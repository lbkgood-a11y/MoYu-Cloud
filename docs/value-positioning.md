# MoYu-Cloud 项目价值定位

## 核心价值主张

MoYu-Cloud 面向中小研发团队、企业内部 IT 团队、软件外包团队和独立开发者，提供一套可运行、可修改、可部署的业务系统快速构建能力。

我们不追求堆叠功能，而是帮助用户消灭重复劳动，缩短从项目启动到系统交付的路径。

> 用更少的重复开发，交付更多真正有价值的系统。

## 用户价值

### 对研发团队

- 减少项目初始化和通用模块开发时间
- 统一权限、日志、异常处理和工程规范
- 让开发者专注业务本身，而不是重复搭建基础设施

### 对外包与实施团队

- 提高单个项目的交付速度
- 沉淀可复用的行业模板和业务组件
- 在相同人力下承接更多项目，提升项目利润空间

### 对企业内部 IT 团队

- 更快交付内部管理和运营系统
- 降低长期维护和技术栈分散带来的成本
- 支持私有化部署，保障数据和代码可控

### 对独立开发者

- 快速验证产品想法
- 获得清晰、标准、可继续维护的代码
- 不被平台锁定，可以独立部署和持续扩展

## 差异化定位

MoYu-Cloud 不是单纯的低代码工具，也不是只有脚手架的代码仓库，而是连接“工程基础”和“业务交付”的快速构建平台。

| 常见方案 | 用户痛点 | MoYu-Cloud 的选择 |
| --- | --- | --- |
| 从零搭建 | 启动慢、重复劳动多 | 提供可运行的默认工程 |
| 重型低代码平台 | 学习成本高、平台锁定 | 生成标准代码并支持导出 |
| 单纯代码脚手架 | 解决启动，不解决交付 | 覆盖建模、权限、部署和运维 |
| 定制项目开发 | 每次重复实现基础能力 | 将经验沉淀为模板、模块和插件 |

## 产品承诺

### 对用户的承诺

- 默认方案足够正确，项目创建后能够快速运行
- 高频业务能力开箱即用，减少重复实现
- 生成结果透明可控，代码归用户所有
- 能够独立部署，不依赖平台在线服务
- 文档、示例和验证路径清晰，降低上手门槛

### 对项目自身的约束

- 不为追求功能数量牺牲易用性
- 不用复杂配置掩盖产品边界
- 不把平台依赖包装成用户价值
- 每项能力都要能够说明节省了哪一类时间

## 商业与运营价值

MoYu-Cloud 适合采用“开源底座 + 增值服务”的发展方式：

- 开源核心框架和基础能力，用于建立信任和开发者入口
- 通过企业版、私有化部署、技术支持和实施服务实现收入
- 通过模板、插件和行业解决方案形成可复用资产
- 通过真实案例证明项目带来的时间节省和交付效率提升

## 第一性验证指标

项目价值是否成立，优先看以下结果，而不是单纯看功能数量或关注者数量：

- 新用户能否在 30 分钟内跑通一个可部署项目
- 一个标准业务模块能否在 15 分钟内完成初版交付
- 用户是否愿意把生成项目用于真实业务
- 用户是否持续复用模板、组件和流程
- 用户是否愿意为私有化、支持或高级能力付费

## 最终定位

> MoYu-Cloud 是开发团队的业务系统交付加速器：让开发少走弯路，让系统快速落座，把重复劳动交给工程化，把自由时间还给创造者。
