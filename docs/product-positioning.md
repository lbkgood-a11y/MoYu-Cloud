# MoYu-Cloud 产品定位

## 一句话定位

MoYu-Cloud 是独立开发者的创作神器：通过统一模板、业务建模和代码生成，把想法快速变成可运行、可修改、可独立部署的真实产品。

## 产品使命

把从想法到产品之间的重复工作工程化，让一个人也能持续创作和发布产品。

## 产品口号

> 从业务模型，到可部署代码。

## 品牌副标题

> 少写重复代码，把时间留给真正的业务。

## 核心用户

- 独立开发 SaaS 和工具产品的个人开发者
- 用 AI 编程但希望保持项目结构和代码控制权的创作者
- 需要快速验证多个产品想法的技术创业者

## 核心问题

1. 一个业务对象需要重复编写表结构、接口、页面、校验和权限。
2. 字段级权限、审计和脱敏容易遗漏，返工成本高。
3. 低代码平台往往锁定运行环境，传统脚手架又只解决项目启动。
4. 需求变更后，重新生成容易覆盖手工代码。

## 产品边界

MoYu-Cloud 专注“想法到产品”的个人创作链路，不替代通用后台框架、云平台或 AI 编程工具；它把验证过的个人模板、模块和部署方式沉淀下来。生成结果必须属于创作者、可进入 Git、可独立部署。

## 产品形态

| 能力 | 结果 |
| --- | --- |
| 数据建模 | 定义表、字段、关系和约束 |
| 页面与 API 生成 | 产出列表、表单、查询和接口代码 |
| 权限规则 | 生成按钮、字段读写、数据范围和脱敏策略 |
| 增量更新 | 预览差异，保留用户手工代码 |
| 创作模板 | 按个人偏好的技术栈生成可运行项目 |
| 独立部署 | Docker、本地运行和项目文档一并生成 |

## 第一性目标

创作者在 10 分钟内把一个想法变成可运行的产品骨架，并在 1 小时内完成首个可用功能。
