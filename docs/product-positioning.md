# MoYu-Cloud 产品定位

## 一句话定位

MoYu-Cloud 是一套面向中小团队和企业研发团队的业务系统快速构建平台，帮助团队更快启动项目、复用通用能力、稳定完成交付。

## 产品使命

把成熟的工程实践沉淀为可复用、可配置、可维护的产品能力，让开发者把时间花在理解业务和创造价值上，而不是重复搭建、反复联调和无效排错。

## 产品口号

> 让开发少走弯路，让系统快速落座 —— MoYu-Cloud，为你争取每一分钟自由。

## 项目内核

> 极致提效、开箱即用、拒绝无效加班。

## 目标用户

- 希望快速启动项目的研发团队
- 需要统一技术基础和交付规范的企业
- 正在建设中后台、运营平台和内部系统的产品与技术团队
- 追求更高研发效率和更低维护成本的个人开发者

## 核心问题

1. 新项目从工程初始化到第一个可用版本耗时过长。
2. 用户、权限、日志、文件、字典等通用能力被重复开发。
3. 字段、页面、流程和权限的常见变化会引发多层代码返工。
4. 部署、监控、排错和回滚没有形成统一、简单的交付路径。

## 产品边界

MoYu-Cloud 负责消灭重复劳动，不替开发者决定业务本身。平台提供可靠默认方案、生成标准代码和开放扩展能力；复杂或特殊业务仍由团队掌握最终实现权。

## 产品设计原则

### 默认正确

提供清晰的默认目录、权限、日志、异常处理和部署方案，高级配置按需开放。

### 开箱即用

创建项目后即可运行、调试和部署，减少从零搭建与反复配置。

### 代码可拥有

生成标准代码，支持 Git 管理、手工扩展和代码导出，避免平台锁定。

### 自动化优先

凡是高频、重复、规则明确的工作，优先考虑自动生成、自动校验、自动部署或自动提醒。

### 交付结果导向

以项目启动时间、功能交付时间、上线步骤、问题定位时间和加班减少量衡量价值，而不是单纯追求功能数量。

## 产品形态

| 层级 | 主要能力 | 用户价值 |
| --- | --- | --- |
| 项目脚手架 | 单体、前后端分离、微服务、SaaS 等模板 | 快速启动 |
| 通用能力中心 | 用户、组织、权限、日志、文件、字典、通知等 | 避免重复开发 |
| 业务建模工作台 | 数据表、字段、表单、列表、查询和 CRUD 生成 | 快速实现业务模块 |
| 流程与规则引擎 | 审批、状态机、条件分支、事件和通知 | 降低流程开发成本 |
| 交付运维中心 | 构建、部署、迁移、监控、日志和回滚 | 缩短交付链路 |

## 第一性目标

> 新用户在 30 分钟内创建一个具备登录、权限、用户管理、业务 CRUD 且可以部署的系统。
