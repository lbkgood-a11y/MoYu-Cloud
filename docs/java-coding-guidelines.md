# Java 编码规范

MoYu-Cloud 后续生成和提交的 Java 代码必须遵循以下要求：

- 类、方法、关键字段和复杂业务逻辑必须带有准确的中文注释
- 公共类和公共方法使用 Javadoc 风格中文注释
- 包名全部使用小写，类名使用大驼峰，方法和变量使用小驼峰
- 优先使用构造器注入，不使用字段注入
- Controller 只处理接口编排，业务逻辑放入 Service
- 请求和响应对象使用独立 DTO，不长期嵌套在 Controller 中
- 业务模块按领域划分，禁止无边界地堆积到 `api` 包
- 常量使用全大写下划线命名
- 异常不得静默吞掉，必要时保留原始异常作为 cause
