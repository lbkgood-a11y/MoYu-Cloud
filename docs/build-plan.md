# MoYu-Cloud 构建计划

## 总体目标

围绕“想法到可运行产品”建立独立开发者的最短创作链路。每个阶段都必须产出真实可运行的产品结果。

## 阶段一：单模块闭环

- 业务对象、字段、校验和基础关系建模
- 列表、表单、查询、API 和数据库迁移生成
- 按钮、字段读写、数据范围和脱敏规则生成
- 生成项目本地运行、Docker 部署和文档导出

验收：一个产品想法从初始化到运行 ≤ 10 分钟。

## 阶段二：可控生成

- 生成文件预览和差异比较
- 增量生成与用户代码保护
- 导入导出、批量操作和页面布局配置
- 团队模板和命名规范

## 阶段三：个人创作资产

- 自定义个人技术栈和项目模板
- 模块、字段、规则和页面片段复用
- 模板版本、兼容性和回滚
- CLI/API 集成现有 Git 与 CI 流程

## 暂不投入

完整后台脚手架生态、在线低代码运行平台、流程设计器、多租户 SaaS、服务治理和插件市场。

## 核心指标

| 指标 | 目标 |
| --- | --- |
| 想法到可运行骨架 | ≤ 10 分钟 |
| 首次生成可编译运行率 | 100% |
| 增量生成覆盖用户代码 | 0 |
| 生成模块真实项目复用 | 持续增长 |
