# MoYu-Cloud

> 从业务模型，到可部署代码。

## 项目介绍

MoYu-Cloud 是独立开发者的创作神器：把一个想法快速变成可运行、可修改、可独立部署的真实产品。

我们坚持的项目内核是：**模型驱动、代码可拥有、交付可验证**。

## 我们解决什么问题

- 重复编写业务表单、列表、接口和权限
- 字段权限、校验和审计容易遗漏
- 需求变更后重新生成会覆盖手工代码
- 低代码平台锁定运行环境，脚手架又不理解业务模型

## 核心价值

| 价值 | 说明 |
| --- | --- |
| 模型驱动 | 从业务对象和规则生成模块代码 |
| 代码可拥有 | 生成结果可审查、进 Git、独立部署 |
| 增量可控 | 预览差异并保护手工代码 |
| 个人复用 | 把做过的模块沉淀为自己的创作资产 |

## 适用场景

适用于独立开发 SaaS、管理后台、运营工具和垂直应用的个人开发者。
